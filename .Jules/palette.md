## 2026-07-28 - [Keyboard Navigation/Shortcuts]
**Learning:** Operators of proxy tools heavily utilize keyboard-driven workflows. Clicking a "Send" or "Decode" button repeatedly when testing request segments can be fatiguing.
**Action:** Always implement `Ctrl+Enter` / `Cmd+Enter` keyboard shortcuts on raw text/request editors to trigger the primary actions (like "Send" in Repeater and "Decode" in Decoder), paired with visible button tooltips.
