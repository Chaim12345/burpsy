2. Data flow diagram

API calls feeding the Dashboard:

GET /api/dashboard → useDashboard() → data.exchanges, data.messages, data.stored_bytes, data.tasks_running, data.tasks, data.summaries, data.sources, data.activity, data.events
GET /api/issues → useIssues() → issues.data.counts.critical/high/medium/low/info/unrecognised
GET /api/scanner/live → useScannerLive() → live.data.findings, live.data.enabled
SSE /api/events → useEventStream() → real-time invalidation

3. Widget interaction map

Internal interactions (same page):

RefreshButton → refetch() → invalidates all dashboard queries → all widgets update
New scan → setScanOpen(true) → opens NewScanModal
New live task → setLiveOpen(true) → opens NewLiveTaskModal
Open HTTP history → setRoute("history") → navigates to Proxy→HTTP history

External interactions (other pages):

Open HTTP history → useApp.setRoute("history") → /history page
CoverageCard → read-only display (no click)
ActivityTable → read-only display (no click)
TaskTable → cancel button (if task running)
