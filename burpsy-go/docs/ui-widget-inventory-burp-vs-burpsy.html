Burp tools burpsy doesn't have

  • Scanner — no scan configuration UI, no scan queue UI, no live audit controls
  • Burp AI — no AI tab
  • Replayer — no replay UI

burpsy tabs Burp doesn't have as tabs

  • Session — Burp has session handling under a menu, not a tab
  • Decoder — Burp has it as a utility accessible from menus
  • Discover — Burp has content discovery under Target → Site map

What burpsy does better than Burp

  • Dashboard — honest coverage accounting with gated work counted separately
  • Logger — per-tool capture toggles and dropped-request counters (Burp lacks)
  • Match & Replace — draft test panel (Burp requires installing first)
  • Issue definitions — lists all 183 (Burp hides some)
  • Intercept — explicit WebSocket direction filters
  • Comparer — byte-level badge (Burp has word-level and byte-level)
  • Session — cookie jar with refresh, wired badge
  • Decoder — pipeline-based with hash step (Burp is single-shot)
